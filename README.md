# The Wright Touch Quote (version 2)

A quote calculator for The Wright Touch cleaning services. It captures the customer and property details and works out a quote from the rates per square metre and per carpet clean.

**Live:** https://brucewade15.github.io/wright/

## How it works

- One self contained `index.html`. There is no build step and nothing to install.
- To run it on your own computer, open `index.html` in a browser.
- Hosted on GitHub Pages from this repo, so a push to the main branch updates the live site.
